### 2.2 Electrocardiogram (ECG) Representation Audits
*   **Representation Metrics**: CKA (Centered Kernel Alignment) and PWCCA (Projection-weighted Canonical Correlation Analysis) are calculated layer-wise between base clean-trained models and domain-adapted models.
*   **FDR Control**: False Discovery Rate (FDR) control is enforced over candidate features to ensure statistical authenticity of clinical detections.
