## 🛰️ Telemetry & Experiment Pipeline Bridge

The frontend connects directly to a Python computation pipeline via dynamic, stale-safe HTTP polling hooks using **SWR**. Telemetry files are serialized as static assets inside `/public/artifacts/`:

1. **`useTelemetry`**  
   Fetches `/artifacts/telemetry/lorenz_telemetry.json`. Retrieves 3D coordinates generated by numerical integration solvers (Runge-Kutta 4th Order), along with maximum Lyapunov exponents ($\lambda_{\max} > 0$), entropy metrics, and parametric systems ($\sigma$, $\rho$, $\beta$).
   * *Autorefresh interval:* 5000ms.
   
2. **`useExperimentData`**  
   Fetches `/artifacts/experiments/pipeline_state.json`. Monitors script status (`idle` / `running` / `completed` / `failed`), progress metrics, step checkpoints, and console logs.
   * *Autorefresh interval:* 3000ms.

3. **`useScientificArtifacts`**  
   Fetches `/artifacts/embeddings/latent_embeddings.json`. Resolves high-dimensional PCA projection coordinates, neighborhood curvatures, and DBSCAN labels to render interactive scatter charts.

## 📚 Centralized Data Layer & Peer-Reviewed Bibliography

All scientific and learning data models are unified in a single registry registry `dashboard/data/index.ts`. It acts as the single source of truth and exposes fast helper indices:

* `getFindingById(id)`: O(1) access to active research findings.
* `getHypothesisById(id)`: O(1) access to active research hypotheses.
* `getOpenQuestionById(id)`: O(1) access to unresolved research questions.
* `getConceptById(id)`: O(1) access to educational concept pathways.
* `getBibliographyEntryById(id)`: O(1) access to academic references.

## Runtime Safety Walkthrough (FASE 3.1)

The stabilization pass keeps the existing App Router, SWR polling, cinematic UI, and compare architecture intact while hardening runtime behavior:

1. **React hydration consistency**
   * Interactive signal and noise plots now use deterministic pseudo-noise instead of render-time `Math.random()`.
   * Telemetry seed log identifiers are stable across prerender and hydration.
   * Critical routes are covered by Playwright console guards for runtime errors and hydration warnings.

2. **Realtime transport fallback**
   * `lib/realtime` treats `socket.io-client` as optional.
   * The adapter lazy-loads the socket transport only in the browser and falls back to polling when the package is absent or invalid.
   * Socket payloads remain `unknown` until guarded or delivered through typed subscriptions.

3. **Lifecycle cleanup**
   * Replay, latent evolution, telemetry streaming, and export timers now clear on pause, reset, disconnect, or unmount.
   * Export completion timers are guarded against state updates after unmount.

4. **TypeScript propagation**
   * Unsafe `any`, suppressions, and `as unknown` casts were removed from runtime code.
   * Export payloads use typed `ExperimentSession` and benchmark rows instead of loose records.

5. **QA expansion**
   * Playwright now validates compare route loading, synchronized delta metrics, replay timeline rendering, telemetry pause/resume and severity filters, JSON/CSV exports, responsive overflow, and runtime console cleanliness.
