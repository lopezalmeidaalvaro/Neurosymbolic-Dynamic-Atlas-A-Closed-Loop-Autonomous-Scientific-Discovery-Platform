How the Demo Works

The demo is intended for engineering students, CubeSat teams, researchers, and professors evaluating the model workflow.

1

Adjust parameters

Set heat load, radiator area, emissivity, thermal capacity, and starting temperature.

2

Run the simulation

Submit the parameters to the REST API or use the web controls.

3

Observe evolution

Review how node temperatures change across the simulated time window.

4

Compare designs

Run multiple configurations and compare the resulting temperature curves.

API Quickstart

Use a configurable base URL so examples work with hosted deployments, tunnels, or local development. 

import json
import os
import urllib.request

API_BASE_URL = os.environ.get("API_BASE_URL", "https://your-api-url")
API_KEY = os.environ.get("ASTOS_API_KEY", "replace-with-your-api-key")

payload = {
    "power": 30.0,
    "area": 0.15,
    "emissivity": 0.85,
    "heat_capacity": 500.0,
    "initial_temp": 25.0,
}

request = urllib.request.Request(
    f"{API_BASE_URL}/v1/simulate",
    data=json.dumps(payload).encode("utf-8"),
    headers={
        "Content-Type": "application/json",
        "X-API-KEY": API_KEY,
    },
    method="POST",
)

with urllib.request.urlopen(request) as response:
    result = json.loads(response.read().decode("utf-8"))
    print(result["max_temp_c"])
API_BASE_URL="https://your-api-url"
