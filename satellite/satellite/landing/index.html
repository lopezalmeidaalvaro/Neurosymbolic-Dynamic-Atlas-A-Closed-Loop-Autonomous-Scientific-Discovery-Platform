API Quickstart

Use a configurable base URL for hosted deployments, tunnels, or local development.

API_BASE_URL="https://your-api-url"
ASTOS_API_KEY="replace-with-your-api-key"

curl -X POST "${API_BASE_URL}/v1/simulate" \
  -H "Content-Type: application/json" \
  -H "X-API-KEY: ${ASTOS_API_KEY}" \
  -d '{
    "power": 30.0,
    "area": 0.15,
    "emissivity": 0.85,
    "heat_capacity": 500.0,
    "initial_temp": 25.0
  }'
